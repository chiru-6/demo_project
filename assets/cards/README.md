# Card Images for Home Dashboard

Place your card images in this folder. The app looks for these filenames:

| Card | Filename |
|------|----------|
| Dashboard | `dashboard.png` |
| Dataset Manager | `dataset.png` |
| Visualizations | `visualizations.png` |
| AI Chatbot | `ai_chatbot.png` |

**Supported formats:** PNG, JPG, JPEG (PNG recommended for transparency).

---

## Free Image Sources

### Icons & Illustrations (recommended for cards)

- **Flaticon** – https://www.flaticon.com  
  Search: "dashboard", "folder database", "chart", "robot chatbot"

- **Icons8** – https://icons8.com/icons  
  Search: "analytics dashboard", "dataset", "charts", "ai assistant"

- **Undraw** – https://undraw.co/illustrations  
  Free SVG illustrations (convert to PNG if needed)

- **Storyset** – https://storyset.com  
  Customizable illustrations

### Stock Photos (for more realistic card images)

- **Unsplash** – https://unsplash.com  
  Search: "dashboard analytics", "data visualization", "ai technology"

- **Pexels** – https://www.pexels.com  
  Free stock photos
