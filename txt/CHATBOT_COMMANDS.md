## Chatbot Command Examples

Use these example questions in the **Chatbot** tab to query your test data.

### 1. Counts / “How many …”

- **Total records**
  - “How many records are there in the database?”
  - “What is the total number of records?”

- **By project**
  - “How many records are there for each project?”
  - “How many tests are there per project?”

- **By test rig**
  - “How many tests were run on each test rig?”
  - “How many records are there per test rig?”

- **By system code**
  - “How many HYD systems are there?”
  - “How many ELE systems are there?”
  - “How many PNEU systems do we have?”
  - “How many GEN systems do we have?”
  - “How many AVIONICS systems are there?”

- **By results / remarks**
  - “How many results remarks are under review?”
  - “How many records are pending?”
  - “How many NOT OK results are there?”
  - “How many OK results do we have?”

### 2. Listing values

- **Projects**
  - “List all projects.”
  - “Show all project names.”

- **Test rigs**
  - “List all test rigs.”
  - “Show all test rig names.”

- **Sample data**
  - “Show all data.” (shows a limited sample)
  - “List all records.” (limited sample, not the full database)

### 3. High-level overview

- “Give me an overview of the database.”
- “Tell me about my test data.”
- “What does this database contain?”

### 4. Mixed natural-language questions

- “How many tests are OK versus NOT OK?”
- “Which test rigs are used the most?”
- “Which projects are present in the database?”
- “How many tests are currently under review or pending?”
